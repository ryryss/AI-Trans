# AI-Trans

**开源的 Chrome AI 翻译插件。用你自己的 Key，用你自己选的模型，零冗余。**

AI-Trans 是一款极简的 Chrome 扩展，用 AI 把整个网页**原地翻译**成你的语言——保留原始排版、字体和交互。与 Chrome 自带的翻译不同，它使用**你自己选择的 AI 模型**和**你自己的 API Key**：没有订阅费、没有中转服务器、不收集任何数据。

> 只做好一件事：专注翻译。没有聊天、没有侧边栏、没有任何多余功能——它只负责翻译。

## ✨ 功能特性

- **原地翻译** — 只替换网页中的文字节点，排版、字体、链接、按钮、表单全部保持原样可用
- **自带 Key，主流模型** — 开箱即用：DeepSeek、OpenAI、Google Gemini、Anthropic Claude、OpenRouter、Moonshot Kimi、智谱 GLM、通义千问、Groq、SiliconFlow、本地 Ollama
- **自建 / 冷门接口** — 任何 OpenAI 兼容服务都可以：自己填 Base URL + API Key + 模型名即可
- **智能动态内容** — 游戏、直播、无限滚动：新渲染或被改写的文字会在浏览时自动跟进翻译
- **可拖动浮动按钮** — 一键翻译、一键还原，位置自动记忆
- **文本翻译面板** — 浮动输入框（类似谷歌翻译）：输入任意内容、自动检测源语言、一键互换语言
- **本地翻译缓存** — 翻过的句子缓存在浏览器里（上限 2 万条 / 约 200 万字符，LRU 自动淘汰），再次访问秒开且零花费
- **用量与余额显示** — 请求次数、输入/输出 tokens、预估费用（按服务商官方单价，目前仅 DeepSeek），以及官方接口查询的真实余额（支持 DeepSeek、OpenRouter、Moonshot、SiliconFlow）
- **内置诊断工具** — 一键测试连接、拉取模型列表（杜绝 404），所有错误都用通俗语言解释并附带解决办法
- **设置自动保存** — 没有"保存"按钮，改什么存什么（清空密钥输入框即删除密钥）
- **界面完全本地化** — 英文、简体中文、繁體中文、日本語、한국어、Deutsch、Français、Español、Русский、Português (BR)，默认跟随浏览器语言
- **隐私优先** — API Key 只在你浏览器里，除了发给你选择的服务商外不会离开本机；本项目没有任何服务器

## 🚀 安装

### 从 Chrome 应用商店
*即将上线。*

### 从 Release 下载（无需 git）
1. 从 [Releases](https://github.com/ryryss/AI-Trans/releases) 下载最新的 `ai-trans-*.zip` 并解压。
2. 打开 `chrome://extensions`，开启右上角「**开发者模式**」。
3. 点击「**加载已解压的扩展程序**」，选择解压后的文件夹。
4. 建议把 AI-Trans 图标固定到工具栏。

### 从源码安装（开发者）
1. 克隆或下载本仓库。
2. 打开 `chrome://extensions`，开启右上角「**开发者模式**」。
3. 点击「**加载已解压的扩展程序**」，选择本项目文件夹。
4. 建议把 AI-Trans 图标固定到工具栏。

## 📖 使用教程

### 第 1 步 — 选择服务商并填入密钥
1. 点击工具栏的 AI-Trans 图标。
2. 选择 **AI 服务商**（DeepSeek、OpenAI、Gemini、Claude……）。
3. 粘贴 **API 密钥**（输入框右侧有该服务商的密钥申请页链接）。
4. 选择 **模型**——更推荐点「**获取模型列表**」：直接从你这把 key 实际可用的模型名里选（强烈推荐，可彻底避免 404 错误）。
5. （可选）点「**测试连接**」确认你的网络能连通服务商。

> 💡 **所有改动即时自动保存，没有"保存"按钮。** 想删除某个已保存的密钥，把输入框清空即可。服务商选择也会被记住：切到 GPT 后关掉面板，下次打开依然是 GPT。

### 第 2 步 — 翻译网页
- 在任意网页按 **Alt+A**，或点击右下角的蓝色浮动按钮。
- 文字被**原地替换**：排版、字体、链接、表单照常工作。
- 右下角气泡会显示翻译进度和本次消耗的 tokens。

### 第 3 步 — 还原原文
- 点击白色浮动还原按钮、再按一次 Alt+A，或在面板里点「还原原文」。

### 自动翻译
- 「本网站自动翻译」— 当前网站所有页面打开即翻，动态内容（游戏题目、无限滚动、实时文字）也会持续跟进翻译。
- 「所有网站自动翻译」— 所有网站都自动翻译（已是你的语言的页面会自动跳过，不浪费额度）。

### 浮动按钮
- 可以拖动：按住移动到任意位置，位置在所有网页间记忆。

### 文本翻译面板
- 点击浮动按钮中的「✎」打开翻译输入框（类似谷歌翻译）。
- 左侧输入原文（输入后 0.6 秒自动翻译），右侧显示译文（只读）。
- 顶部：源语言默认「**自动检测**」（检测结果显示在其右侧，如「自动检测（英语）」），⇄ **互换语言**按钮，目标语言默认跟随浏览器语言。
- **互换**同时交换语言和内容（谷歌翻译风格）：旧译文变成新原文，并重新翻译成新目标语言。若输入内容与所选源语言不符，面板会自动检测并纠正源语言。
- 每次翻译完成后，左下角显示**本次消耗的 tokens**；命中缓存时显示「已用缓存翻译（无需 API）」。
- **语音朗读**：点击原文或译文上方的 🔊，用系统本地语音朗读（免费、离线）。若未安装对应语言的语音，会提示你去系统设置中添加。
- 窗口可**按住标题栏拖动、拖拽右下角改变尺寸**，位置、尺寸与语言选择自动记忆；点 × 关闭。

### 统计与余额
- 面板显示**今日**和**累计**的请求次数、输入/输出 tokens（本地统计）。
- 选择 DeepSeek 时，还会显示**预估费用**（按官方单价，区分高峰/空闲时段）。
- 选择支持的服务商（**DeepSeek、OpenRouter、Moonshot、SiliconFlow**）时，会通过官方接口查询你的**真实余额**。OpenAI、Gemini、Claude 等没有公开的余额查询接口，因此不显示余额行。

### 界面语言
- 默认「自动」跟随**浏览器语言**（支持 10 种语言）。
- 一旦手动选择某种语言，将**严格全程使用该语言**——面板、页面气泡、浮动按钮、错误提示全部一致。

### 清空数据
- 面板底部「**重置所有数据**」可清空密钥、缓存、统计、设置和按钮位置；已打开的页面会还原为原文，所有标签页的内存缓存同步清空（防止旧缓存被写回）。卸载扩展同样会清除全部数据。

## 🔧 自定义 / 自建接口

任何遵循 OpenAI chat-completions 协议的服务都可以接入：

1. 在面板中选择「**自定义（OpenAI 兼容）**」。
2. 填入 Base URL（例如 `https://your-host/v1`）、API Key 和模型名。
3. 完成——设置自动保存。

## 🧠 工作原理

```
网页文字节点 → 过滤（跳过代码/输入框/隐藏元素）→ 逐句查缓存
    → 未缓存的文字分批（每批≤8000 字）并发 5 路发送给所选模型
    → 返回 JSON 译文数组，写回原文字节点（布局不动）
```

一个 `MutationObserver` 监听新增或被改写的文字（`childList` + `characterData`），保证动态内容持续翻译。

## 🔒 隐私

- 无遥测、无统计埋点、无外部服务器。
- 请求从你的浏览器直接发往你配置的 AI 服务商。
- 缓存、设置、统计只保存在你的浏览器本地存储中。

## ❓ 常见问题

- **翻译没反应？** 检查 API 密钥和模型；`chrome://` 等内部页面无法翻译。安装前打开的旧页面需要刷新。用面板里的「测试连接」和「获取模型列表」排查。
- **404 等错误是什么意思？** 所有错误都有通俗解释和解决办法：404 → Base URL 或模型名不对；401 → 密钥无效/过期；402 → 余额不足；403 → 密钥没有该模型权限；429 → 限流或今日免费额度用完；5xx → 服务商服务器故障，稍后重试；超时/网络错误 → 你的网络到服务商不通。
- **我在中国大陆，海外服务商连不上？** Google/OpenAI/Anthropic 的接口在大陆一般无法直连。请使用代理，或改用国内服务商：SiliconFlow、智谱、DeepSeek 都可以直连。
- **怎么删除已保存的密钥或清空所有数据？** 把密钥输入框清空即可（自动保存）；或点击面板底部「重置所有数据」。卸载扩展也会清除全部数据。
- **翻译缓存有上限吗？** 有——按"语言+网站"最多保存 **2 万条 / 约 200 万字符**（先到为准），超出后按 LRU（最久未用）自动淘汰；浏览器存储配额不足时会自动丢弃最旧的一半后重试写入。用量统计只保留最近 30 天。
- **翻译有点慢？** 使用快速的非推理模型。DeepSeek 的思考模式已被插件自动关闭；服务商高峰时段也会影响速度。
